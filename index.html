TimeCrashGames - DARKWATCH

I've been working with Simon Tapping on a FPS shooter where you're tasked with fighting Cthulhu type horrors. To be completely honest he's very knowledgeable in the Unreal editor, and all the 3rd-party applications (like blender/substance painter/and so on.) But, with any indie project with him, we never finish it. Some issue ALWAYS comes up. We always get about 75-80% done and some sort of problem arises. Also, the group completely re-scopes the game nearly every 6 months. This was supposed to be a 1-year out-the-door game and it's been going on for 3 years. I don't think I can count how many different iterations we've had of how this game. And now, NO ONE is working on it.

Add it to the list of games started by TimeCrash and never finished; 9 REALMS (legal issues), CIRG, Unnamed toy tank game, and more...

Nothing against Simon. I consider him my bestfriend but I really wish I could have project with my name in it.
